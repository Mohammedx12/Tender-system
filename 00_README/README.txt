Tender Readiness Audit (Add-On Kit)
================================

Purpose
- A client-facing deliverable package for your 2-hour Tender Readiness Audit.
- Designed to plug into the Tender OS Kit you already have.

Audit flow (2 hours)
1) 15 min: Context & target tenders (sector, entity types, typical values)
2) 45 min: Document/evidence review using Evidence Request checklist
3) 45 min: Process review using Interview Guide + quick walkthrough of past tenders
4) 15 min: Scoring + top gaps + next steps

Deliverables
- Readiness Scoring Rubric (Excel) with weighted score + maturity tier
- Audit Report Template (Word) – executive summary + roadmap + quick wins
- Interview Guide (Word) – structured questions by function
- Evidence Request Checklist (Excel) – what to request before audit
- Optional: Client Scorecard tracker (Excel)
